# Website for French Creek Carpentry
Check out this website by doing the following: 
* Clone this repository
* Make sure you're in the main directory for this web app after cloning 
* Install the necessary dependencies needed to run the app
  * run **npm i** to install
* In your terminal run **node index.js**
* To visit the web app
  * Open your favorite web browser
  * In the web address bar type **localhost:3000**
  * Enjoy the app
